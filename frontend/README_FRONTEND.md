# Metro Mate - Frontend

This is the frontend for the Metro Mate project. It has been converted from a React/Tailwind project to a Vanilla HTML/CSS/JS project using Jinja2 templates.

## Structure
- `templates/`: Contains Jinja2 HTML templates.
  - `partials/`: Reusable components like Navbar and Footer.
- `static/`: Static assets.
  - `css/style.css`: Main styling for the project.
  - `js/main.js`: Shared JavaScript logic.
  - `images/`: Images and icons.

## Key Pages
- `index.html`: Home page.
- `stations.html`: Station search and facilities.
- `nearby_places.html`: Attractions near stations.
- `lost_found.html`: Lost and Found reporting.
- `book_ticket.html`: Ticket booking and fare calculation.
- `smart_card.html`: Smart card management.
- `user_dashboard.html`: User travel history and insights.
- `auth.html`: Login and signup.
- `admin_dashboard.html`: Admin overview.
- `analytics.html`: Detailed reports for admins.
